# Root & Bloom AI Studio

Every AI tool a salon needs, rooted in one simple studio, for the stylists and salon owners of [Root & Bloom Salon Source](https://rootbloomsalonsource.com).

**Live preview:** https://dshenterpriseinc.github.io/rootbloom-ai-studio/

Write client texts and rebooking reminders, design salon flyers and social graphics, make short reels, voiceovers and talking-photo videos, build education-night slide decks, translate client notices, and put together a brand kit, all in plain words, with Bloom the sunflower guide to help.

Built on the BizConnect AI Studio core (a white-label AI studio). Developers and AI agents: see [AGENTS.md](AGENTS.md).

*Preview prototype. Sign-in uses a private access passcode.*
